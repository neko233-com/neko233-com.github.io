隐私说明

适用于 Nerilo233 当前开发构建。生效日期：2026-10-24。

当前系统连接功能尚未开放。上线任何流量转发或 DNS 功能之前，会先更新本说明及应用内的使用前披露。

1. 设备上的数据

配置、服务器凭据和订阅地址保存在本机钥匙串，使用仅限此设备的存储设置。所选线路、连接偏好和隐私说明确认状态保存在应用本地设置中。应用没有云同步或账号系统。

系统连接实现仍在开发。相关共享配置文件的设计使用 iOS 文件保护并排除备份；异常退出后可能需要下次清理。当前连接入口保持不可用。

2. 主动更新订阅

只有在你主动选择读取或更新订阅时，应用才请求你指定的 HTTPS 地址。订阅服务器会处理网络请求、IP 地址及订阅地址中的凭据。开发者不提供订阅服务器，也不会接收这些请求的副本。

3. 开发者的数据处理

应用不包含广告、统计或跟踪 SDK，不上传网络活动或配置给开发者，不出售或将网络活动用于广告。应用不提供服务器或线路账号。当前开发构建不建立系统隧道。

4. 删除与控制

可删除单份配置，或在设置中清除全部本地配置、凭据及订阅地址。卸载应用后，iOS 钥匙串内容仍可能保留，建议卸载前先清除本地配置。若未来添加系统网络配置，可在 iOS 设置中单独移除。

5. 支持邮件与网站

主动发邮件时，你的邮箱地址和邮件内容会由邮件服务商处理，并送达开发者以回复支持请求。可通过 qq1417015340@gmail.com联系或提出删除支持邮件的请求。

此说明页面由 GitHub Pages 托管，没有额外统计脚本、广告或表单。托管服务的网络请求处理适用 GitHub 隐私声明。
