隐私说明

适用于 Nerilo233 普通开发构建与明确标注的设备测试构建。更新日期：2026-10-24。

普通开发构建未开放系统连接。设备测试构建在首次使用前单独展示数据处理与实验性功能说明，允许测试者手动验证系统代理；这不代表已完成真机验证、获准 TestFlight 分发或在 App Store 正式发布。

1. 设备上的数据

配置、服务器凭据和订阅地址保存在本机钥匙串，使用仅限此设备的存储设置。所选线路、连接偏好和隐私说明确认状态保存在应用本地设置中。应用没有云同步或账号系统。

启动设备测试连接时，所选配置经 iOS Network Extension 会话传给本应用扩展；断开后释放会话与配置引用。连接须从应用内发起，系统或按需启动缺少有效配置时会拒绝连接。

2. 主动更新订阅

只有在你主动选择读取或更新订阅时，应用才请求你指定的 HTTPS 地址。订阅服务器会处理网络请求、连接 IP 及订阅地址中的凭据。开发者不提供订阅服务器，也不会接收这些请求的副本。

3. 设备测试版的系统流量与 DNS

仅当你使用明确标注的设备测试构建并主动启动系统连接时，设备流量才经你选择的服务器转发。该服务器运营者会处理连接 IP、目标地址与转发流量；目标服务会收到你发送给它的数据。请只使用自己信任且有权使用的服务器。

连接使用 Cloudflare 的 1.1.1.1 HTTPS DNS 服务，经所选线路发送 DNS 查询。启动时会查询固定域名 example.com 检查线路。Cloudflare 会处理查询的域名与 DNS 请求。应用不会在线路失败时改用直连 HTTPS 解析。所选服务器域名可能先由物理网络的 DNS 解析，相关网络运营者可能处理该请求。

当前设备测试仍存在 TLS 关闭等已知限制。需要停止时，可在应用内断开，或在 iOS 设置中关闭本应用的 VPN 配置。

4. 开发者的数据处理

应用不包含广告、统计或跟踪 SDK，不将配置或网络活动上传给开发者，不出售或将网络活动用于广告。应用不提供服务器或线路账号。上述用户所选服务器、DNS 服务、Apple 测试服务及主动支持邮件的数据处理各有明确用途，见对应说明。

5. Apple TestFlight 测试信息

如果通过 TestFlight 安装，Apple 会按其测试服务政策收集并向开发者提供测试者信息（例如姓名与邮箱）、崩溃日志、使用信息，以及你提交的反馈。这些信息用于诊断和改进测试构建。反馈可能包含截图和设备信息；提交前请检查，避免包含线路密码、订阅密钥或不希望共享的内容。

详见 Apple TestFlight 隐私说明。测试者可在 TestFlight 中停止测试。普通开发构建没有额外的测试分析 SDK。

6. 删除与控制

可删除单份配置，或在设置中清除全部本地配置、凭据及订阅地址。卸载应用后，iOS 钥匙串内容仍可能保留，建议卸载前先清除本地配置。系统网络配置可在 iOS 设置中单独移除；连接期间请先断开再删除配置。

7. 支持邮件与网站

主动发邮件时，你的邮箱地址和邮件内容会由邮件服务商处理，并送达开发者以回复支持请求。可通过 qq1417015340@gmail.com联系或提出删除支持邮件的请求。应用不会自动发送支持邮件。

English summary

Profiles, credentials and subscription URLs stay in the device-only Keychain; local preferences stay in app storage. Subscription servers process requests only when you actively fetch or update. Ordinary development builds disable system tunneling. Explicit device-testing builds allow manual experimental forwarding through your chosen server and Cloudflare HTTPS DNS, including an example.com startup probe. Server hostname bootstrap may use physical-network DNS. No copies of configurations or network activity are uploaded to the developer. Apple TestFlight processes tester details, crashes, usage and submitted feedback under its own policy. Support email is processed only when you choose to send it. Clear local profiles before uninstalling and remove system network settings separately. Device tests and TestFlight availability are not proof of a public release.
